O aplikaciji
TuneWiseALL koristi YouTube Data API v3 i YouTube IFrame Player API za pretragu i reprodukciju javno dostupnog YouTube sadržaja. YouTube je izvor glazbenog sadržaja. TuneWiseALL ne pohranjuje niti distribuira glazbene datoteke.

Pravila privatnosti

Zadnje ažurirano: 2026.

TuneWiseALL je aplikacija koja korisnicima omogućuje pretragu i reprodukciju javno dostupnog glazbenog sadržaja s YouTubea unutar jedinstvenog sučelja.

Podaci koje obrađujemo

Upiti koje utipkate ili izgovorite šalju se našem sigurnom backend servisu (Cloud Run), koji ih prosljeđuje YouTube Data API v3 servisu (Google) isključivo radi dohvaćanja rezultata pretrage. YouTube API ključ nikad ne napušta naš poslužitelj i nije dio ove aplikacije. TuneWiseALL ne vodi korisničke račune i ne prikuplja osobne podatke na vlastitim poslužiteljima.

Mikrofon

Mikrofon se koristi samo kada aktivno pokreneš glasovnu pretragu, uključiš Always Listening način ili pritisneš „Prepoznaj pjesmu". Zvučni isječak za prepoznavanje pjesme šalje se vanjskom servisu za prepoznavanje glazbe samo u trenutku snimanja i ne pohranjuje se unutar aplikacije.

Lokalna pohrana

Favoriti, playliste i postavke spremaju se isključivo lokalno u tvom pregledniku (LocalStorage) i ne šalju se na vanjske poslužitelje. Brisanjem podataka preglednika ili gumbom „Obriši sve lokalne podatke" ti podaci se trajno uklanjaju.

Treće strane

Pretraga i reprodukcija oslanjaju se na YouTube/Google usluge koje imaju vlastita pravila privatnosti. Korištenjem TuneWiseALL prihvaćaš i pravila privatnosti tih usluga.

Kontakt

Za pitanja o privatnosti obrati se administratoru aplikacije putem kontaktnih podataka navedenih na stranici s koje si pristupio/la aplikaciji.

Uvjeti korištenja

Zadnje ažurirano: 2026.

Korištenjem TuneWiseALL prihvaćaš sljedeće uvjete.

Priroda usluge

TuneWiseALL koristi YouTube Data API v3 i YouTube IFrame Player API za pretragu i reprodukciju javno dostupnog YouTube sadržaja. YouTube je izvor glazbenog sadržaja. TuneWiseALL ne pohranjuje niti distribuira glazbene datoteke.

Intelektualno vlasništvo

Sav reproducirani sadržaj vlasništvo je odgovarajućih nositelja prava i dostupan je putem YouTubea. TuneWiseALL ne tvrdi vlasništvo nad tim sadržajem i ne omogućuje preuzimanje ili distribuciju glazbenih datoteka.

Dopuštena upotreba

Aplikacija je namijenjena osobnoj, nekomercijalnoj upotrebi. Korištenjem aplikacije obvezuješ se poštovati YouTube-ove Uvjete korištenja te sve primjenjive zakone.

Dostupnost usluge

TuneWiseALL ne jamči neprekidnu dostupnost pretrage ili reprodukcije, budući da ovisi o dostupnosti vanjskih servisa (YouTube i drugi). Sadržaj pojedinih videa može biti nedostupan za ugrađenu reprodukciju ovisno o postavkama nositelja prava.

Ograničenje odgovornosti

Aplikacija se pruža „takva kakva jest", bez jamstava bilo koje vrste. TuneWiseALL ne odgovara za prekide usluge, netočnost rezultata pretrage ili nedostupnost pojedinog sadržaja.

Izmjene

Ovi uvjeti mogu se povremeno ažurirati. Nastavak korištenja aplikacije nakon izmjena smatra se prihvaćanjem novih uvjeta.
