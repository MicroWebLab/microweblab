O aplikaciji
TuneWiseALL koristi YouTube Data API v3 i YouTube IFrame Player API za pretragu i reprodukciju javno dostupnog YouTube sadržaja u vidljivom, ugrađenom playeru. YouTube je izvor glazbenog sadržaja. TuneWiseALL ne pohranjuje niti distribuira audio/video datoteke.

Pravila privatnosti

Zadnje ažurirano: 2026.

TuneWiseALL omogućuje pretragu i reprodukciju javno dostupnog glazbenog sadržaja s YouTubea unutar jedinstvenog sučelja.

Pretraga

Tekst koji upišeš ili izgovoriš šalje se konfiguriranom backend servisu ove aplikacije. Backend zatim koristi YouTube Data API v3 (Google) za dohvaćanje rezultata pretrage i vraća ih aplikaciji. YouTube API ključ nalazi se isključivo na backend servisu i nije dio ove web aplikacije. Način na koji backend servis obrađuje, bilježi ili zadržava upite ovisi o konfiguraciji tog servisa i nije nešto što ova aplikacija sama jamči ili kontrolira.

Glasovna pretraga i mikrofon

Mikrofon se aktivira isključivo tvojim klikom — na gumb za glasovnu pretragu, na „Always Listening" ili na „Prepoznaj pjesmu". Glasovna pretraga koristi Speech Recognition API (Web Speech API) preglednika. Obrada govora ovisi o pregledniku koji koristiš; neki preglednici tu obradu izvode putem vanjskih/cloud servisa proizvođača preglednika, pa obrada nije nužno isključivo lokalna. Kada koristiš „Prepoznaj pjesmu", aplikacija snima kratak zvučni uzorak (približno 6 sekundi) i šalje ga konfiguriranom backend servisu ove aplikacije radi prepoznavanja pjesme. Backend zatim komunicira s vanjskim servisom za prepoznavanje glazbe i vraća aplikaciji samo izvođača i naziv pjesme. Uzorak se ne pohranjuje unutar aplikacije; kako ga backend i vanjski servis za prepoznavanje obrađuju ili zadržavaju ovisi o njihovoj konfiguraciji i pravilima.

Reprodukcija

Reprodukcija se odvija putem YouTube IFrame Player API-ja u vidljivom, ugrađenom YouTube playeru. Google/YouTube pritom mogu prikupljati podatke u skladu s vlastitim pravilima. Aplikacija ne pohranjuje niti distribuira audio ili video datoteke.

Lokalna pohrana

Favoriti, playliste i postavke spremaju se lokalno u tvom pregledniku (LocalStorage). Spremljeni favoriti i playliste automatski se uklanjaju 30 dana nakon spremanja. Gumbom „Obriši sve lokalne podatke" ili brisanjem podataka preglednika uklanjaju se odmah.

Uvjeti korištenja

Zadnje ažurirano: 2026.

Korištenjem TuneWiseALL prihvaćaš sljedeće uvjete.

Priroda usluge

TuneWiseALL koristi YouTube API Services — YouTube Data API v3 za pretragu i YouTube IFrame Player API za reprodukciju javno dostupnog YouTube sadržaja. YouTube je izvor glazbenog sadržaja. TuneWiseALL ne pohranjuje niti distribuira glazbene datoteke.

Zabranjena upotreba

  • preuzimanje (download) YouTube audio ili video sadržaja
  • ripping i ekstrakcija zvuka
  • trajno spremanje YouTube audio/video sadržaja
  • zaobilaženje ili zamjena YouTube playera
  • blokiranje, skrivanje ili modificiranje YouTube oglasa
  • skrivanje ili prekrivanje ugrađenog playera
  • neovlaštena distribucija sadržaja dohvaćenog putem YouTube API Services

Intelektualno vlasništvo

Sav reproducirani sadržaj vlasništvo je odgovarajućih nositelja prava i dostupan je putem YouTubea. TuneWiseALL ne tvrdi vlasništvo nad tim sadržajem.

Dopuštena upotreba

Aplikacija je namijenjena osobnoj, nekomercijalnoj upotrebi. Obvezuješ se poštovati YouTube Terms of Service te sve primjenjive zakone.

Dostupnost usluge

TuneWiseALL ne jamči neprekidnu dostupnost pretrage ili reprodukcije jer ovisi o dostupnosti vanjskih servisa. Pojedini videozapisi mogu biti nedostupni za ugrađenu reprodukciju ovisno o postavkama nositelja prava.
